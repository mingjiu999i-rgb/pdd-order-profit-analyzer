# 拼多多订单经营分析（本地离线版）

本地导入拼多多订单 CSV、退款 XLSX、资金 ZIP/CSV，按订单原始支付日期生成可追溯的经营分析 Excel。所有业务数据只保存在本机 SQLite 数据库中。

## 主要功能

- 按完整订单号精确关联订单、退款和资金流水。
- 区分未发货成功退款与已发货退款，退款金额以实际资金流水为准。
- 统计订单成交额、有效订单销售额、已发货退款、其他扣款、订单净回款、回款差额、入账完成率与净结算率。
- 推广消耗、推广充值、提现等资金划转不计入订单净回款。
- 支持多店铺自动识别、增量导入、保守去重、导入批次和异常审计。
- 支持按店铺和日期范围筛选，并导出同范围的 Excel 汇总与逐笔明细。
- SKU 成本按店铺分别维护，支持手工填写或批量导入包含“SKU编码”和“总成本”的 CSV/XLS/XLSX。
- 成功导入的原始报表自动归档；无法可靠确定店铺时停止导入并要求确认。

## 运行环境

- Python 3.10+
- `openpyxl`

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

macOS 也可以双击 `启动.command`。默认地址为 <http://127.0.0.1:8765>。

### Windows

1. 安装 [Python 3.10或更高版本](https://www.python.org/downloads/windows/)，安装时勾选 `Add Python to PATH`。
2. 下载或克隆本仓库。
3. 双击 `启动分析.bat`。首次启动会自动创建 `.venv` 并安装依赖，之后会直接打开本地分析页面。

若需要修改项目，可使用 VS Code 打开仓库文件夹。修改后双击 `测试.bat` 运行测试，再重新启动程序查看效果。Windows与macOS使用相同的SQLite数据模型和计算逻辑，但各自的数据文件保存在本机，不随Git同步。

## 日常使用

1. 把订单、退款和资金报表放入程序自动创建的 `导入报表` 文件夹。
2. 启动程序；已识别文件会自动导入并移动到隐藏的 `.data/导入归档`。
3. 在网页中选择店铺和日期范围查看统计。
4. 点击“导出 Excel”，文件会保存到 `导出结果`。

首次建议导入全量数据；日常订单和资金可导入本月1日至昨天，退款滚动导入最近90天。

日期口径：每日主表以订单支付日期为基准；退款和资金通过完整订单号回填到订单原支付日期；推广费按店铺与统计日期直接匹配；SKU 成本没有日期范围，修改后会重新计算历史盈亏。

## 数据安全

`.gitignore` 默认排除 CSV、Excel、ZIP、SQLite 数据库、导入目录和导出目录，避免业务数据被提交到仓库。上传代码前仍应检查 `git status`。

## 测试

```bash
python -m unittest discover -s tests -v
```

真实验收样本不包含在仓库中。如需运行真实样本测试，可设置 `PDD_REAL_ORDER`、`PDD_REAL_REFUND` 和 `PDD_REAL_FUNDS_DIR` 指向本地样本文件。
